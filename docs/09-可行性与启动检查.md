# 09 · 可行性评估与启动检查

## 结论

项目作为“官方自定义剧本中的分层 VLA 研究原型”**可行**；作为当前版本即可稳定完成完整对局的产品，**尚不可行**。代码已具备离线管线、动作 schema、状态机、规则/学习策略接口和 CPU 冒烟测试，但真实游戏闭环仍受采集、感知和安全注入三项外部条件约束。

## 优点

- 分层架构合理：快层承担实时动作，慢层异步规划，避免 4B VLM 直接闭环的延迟问题。
- 动作空间、意图向量和数据格式集中定义，便于替换角色、策略和模型。
- 先规则、再 BC、再 VLA，能够逐级验收并保留可回退基线。
- 默认 dry-run、限定官方沙盒、不使用内存/DLL/hook，合规边界清晰。
- 已覆盖关键历史坑：破译隐式状态、QTE 校准标记、长尾权重、对局记忆、策略可插拔。

## 缺点与风险

- `EventDetector` 和 HUD/目标检测仍是占位实现；因此规则 agent 当前只能扫视移动，不能可靠找机、转点或识别受击。
- 没有真实 session 数据和延迟报告，模型训练与 M1 闭环仍是假设，不能把 forward 通过等同于游戏可玩。
- Qwen/SigLIP 权重、Transformers 多模态 processor、2080 Ti FP16 耗时尚未在本机验收。
- SendInput 带注入标志，仍有封禁/误操作风险；真发送必须人工确认处于自定义剧本或训练营。
- 监督信号主要来自按键启发式，HEAL/RESCUE 等高层意图存在弱监督和分布偏差。

## 启动硬门槛

先运行只读自检：

```bash
python -m idv_agent.scripts.doctor
```

当前已验证环境：Conda `idv312` / Python 3.12.14 / Torch 2.6.0+cu124 / RTX 2080 Ti。`doctor` 仍需在管理员终端且游戏启动后才能通过管理员与窗口两项。

1. Windows 管理员权限下，确认游戏窗口可被列出，DDA 连续采集 60 秒无崩溃。
   使用 `python -m idv_agent.scripts.benchmark_capture --title "第五人格" --seconds 60` 记录 p50/p95、有效 FPS 和空帧率。
2. 在沙盒中仅用 dry-run 验证 ActionDecoder/Executor 的 press-release 对称性，再进行极短真发送测试。
3. 采集至少 3 局人类基线和 3 局规则测试；每局保留 `meta.json`、`frame_timestamps.csv`、事件日志和录像摘要。
4. 以真实时间戳运行 `extract → build_jsonl → stats`，确认图片数、帧数和类别分布一致。
5. 在 2080 Ti 上完成 bc_fast 单 epoch；慢层 Qwen 只在显存、延迟和输出解析有实测后启用。

当前现场进展：已完成 5 秒规则 agent 真发送测试，30 FPS 共 150 帧；观察到视角先右转后左转，符合规则扫描器约 2.5 秒换向逻辑，未报告卡键或崩溃。该结果证明“输入注入 + 调度循环”可用，但尚不等于 M0 延迟门槛已通过；下一次运行需保留 CLI 输出中的 `[latency]` 统计。

### M0 实测结果（2026-08-31）

10 秒规则 agent 真发送测试通过：300/300 帧，30 FPS；抓帧 mean/p95 = 4.58/4.97 ms，决策 mean/p95 = 0.04/0.06 ms，总链路 mean/p95 = 5.20/5.96 ms，最大总延迟 6.85 ms。满足“捕获 ≤33 ms、端到端 ≤150 ms”的 M0 门槛，可进入 M1。

### M1 首批数据结果（2026-08-31）

3 局 session 完整性检查通过，共 22,357 帧；有效 FPS 23.23–23.64（目标 30），真实时间戳已保留。`bc_fast`/`bc_slow` 各 20 steps FP16 均成功保存 checkpoint。当前数据适合验证管线和破译/移动基线，不足以覆盖完整动作空间；下一批采集应定向增加 VAULT、SKILL、救援、治疗、道具和 MAP。

## 接下来两周（按优先级）

| 优先级 | 任务 | 完成标准 |
|---|---|---|
| P0 | M0 采集/注入/延迟实验 | 捕获 ≤33ms、注入 <10ms、端到端 ≤150ms；失败则停在 M0 |
| P0 | 真实 session 数据闭环 | 至少 6 局，`stats` 输出可复核，缺失帧为 0 |
| P1 | HUD 区域与事件检测最小实现 | 能检测破译进度、校准、受击/打断中的至少两项 |
| P1 | 律师规则状态机接入感知 | 沙盒连续运行 5 分钟不出现按键卡死或错误重入 |
| P2 | bc_fast 单 epoch + 离线回放 | loss 可下降，离线动作准确率/混淆矩阵有记录 |
| P2 | 慢层 Qwen 小样本解析 | 结构化 intent/skeleton 解析成功率 ≥95%，并记录单次延迟 |

## 实验记录要求

每次实验记录：代码版本、游戏/地图/角色、管理员状态、显示器分辨率、游戏鼠标灵敏度、目标 FPS、有效 FPS、捕获/决策/注入 p50/p95、是否 dry-run、异常和回放路径。没有这些字段，不判定里程碑通过。

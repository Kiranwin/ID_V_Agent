## 0. 一句话结论

**本项目快慢双系统 + BC→RL→VLA 演进路线与 2025-2026 年行业共识完全一致**：Google / NVIDIA / Figure 三家独立收敛到「慢推理（≤10Hz）+ 快动作（≥100Hz）分离」，VLA 综述明确「分层 VLA 优于单体 VLA」「3B 参数 + 20-50Hz 是可部署 VLA 的工程基线」。本框架无需改方向，只需吸收若干工程细节。

---

## 1. VLA 领域总览（2024-2026）

### 1.1 两条技术路线

| 路线 | 代表 | 优点 | 缺点 |
|---|---|---|---|
| 离散化自回归（动作即语言） | RT-2、OpenVLA(7B) | 无缝继承 LLM 推理、易微调 | 精度受限、推理慢 |
| 连续生成式（diffusion / flow matching） | Octo、π0、GR00T N1 | 50Hz+ 高频控制、连续精细 | 训练更重、需动作专家模块 |

### 1.2 双系统（Dual-System）成为行业共识

- **产品级收敛**：Google（Gemini Robotics）、NVIDIA（GR00T N1/N1.5/N1.6）、Figure AI（Helix）独立收敛到「System 2 慢推理 + System 1 快动作」。
- **研究界**：π0.5/π0.7（subtask + action expert）、DIAL（慢层潜意图 x_t 条件化快层）、RoboDual、DuoCore-FS（真并行快慢 + 潜在缓冲）。
- **结论**：CoRL 2025 趋势「Hierarchical VLAs beat monolithic VLAs for open-world generalization」。

### 1.3 工程基线信号

- 「**3B 参数 + 20-50 Hz**」正在成为 deployable VLA 的新基线（π0、GR00T N1、SmolVLA）；7B+ 在实时控制已显偏大。
- Efficient VLA 综述：OpenVLA-OFT = parallel decoding + action chunking + L1 regression 的组合范式。
- **对本项目**：M3 候选 Qwen3-VL-2B/3B + 轻量 flow matching 头正好落在基线内；M2 的 SigLIP2 回归头是更轻的过渡，方向正确。

## 2. 重点项目逐个拆解

### 2.1 GR00T N1（NVIDIA，2025.03，开源）★ 与本项目架构最同构

- **架构**：2.2B 总参（1.34B Eagle-2 VLM）+ DiT flow matching 动作模块。System 2（VLM 理解）→ System 1（DiT 高频动作），端到端联合训练。
- **数据金字塔**：互联网/人类视频（VQ-VAE latent action + 逆动力学模型 IDM 推断伪动作）→ 仿真合成 → 真机数据。
- **性能**：16 动作 chunk 推理 63.9ms（L40 bf16）。
- **演进细节（N1→N1.7）**：VLM LLM 层物理截断（`select_layer`）取中间层特征；VLM→DiT 之间加 LayerNorm（N1.6）与 SelfAttentionTransformer（N1.7）；`tune_top_llm_layers` 只解冻顶部 LLM 层联合训练。
- **可借鉴**：
  1. 「小 VLM + flow matching 动作头」= 我们 M3 快层 VLA 化的精确形态（审查 P9 的落点）。
  2. **VLM 截断取中间层 + LayerNorm/自注意力预处理**：M3 实现细节，避免整 LLM 前向开销。
  3. 数据金字塔的「无动作录像 → 伪动作标注」：我们已有按键日志（更强监督），但未来多角色/多地图扩展可把**无日志录像**用逆动力学补标注。
  4. 联合训练时只解冻顶部 LLM 层——LoRA 之外的节流手段。

### 2.2 π0 / π0.5（Physical Intelligence）

- **π0**：PaliGemma VLM + flow matching action expert；混合表征 = 离散语义 token（技能/意图）+ 连续动作。
- **π0.5**：两阶段——预训练用 FAST tokenizer 统一离散 token 吞吐海量异构数据；后训练切 flow matching 专家解码高频连续动作。
- **后续**：π0.5-KI（梯度绝缘，VLM 梯度不污染动作专家）→ π0.6 → π0.7；ReinFlow（NeurIPS 2025，在线 RL on flow 策略）；DSRL（CoRL 2025 Oral，在 frozen diffusion 的初始噪声潜空间做 RL，无需 log-prob）。
- **可借鉴**：
  1. **离散语义 + 连续动作混合表征** = 我们「20 离散类 + 4 连续值」的设计动机来源，方向一致。
  2. **梯度绝缘**：慢层 VLM 与快层动作头联合训练时，防止动作梯度反向污染 VLM 意图表征——M3 联合微调时参考。
  3. **flow 策略的在线 RL 已有成熟路径**（ReinFlow/DSRL）——M3 之后的 RL 微调不用等新方法。

### 2.3 FAST（动作 tokenization，2025.01）

- DCT + BPE 压缩动作 chunk：每 1s 动作压缩为 30-60 token，压缩比 5-13x，让自回归 VLA 支持 50Hz+ 高频；π0-FAST 训练提速 5 倍、性能持平 diffusion。
- **对本项目**：动作空间只有 4 个连续值（机器人是几十维高频），**不需要** DCT+BPE 这种重 tokenizer；但「动作 chunk + 时间相关性压缩」思想提示：cam_dx/cam_dy 逐帧高度相关，M3 的 flow matching 头按 chunk 预测（而非逐帧回归）更优。

### 2.4 SIMA 2（DeepMind，2025.11）★ 最贴近「游戏 VLA」

- **架构**：Gemini 2.5 flash-lite 为核心，语言 → 意图 → 计划 → 行动 多步认知链；仅看屏幕像素 + 虚拟键鼠，不访问游戏内部。
- **训练**：人类演示视频 + Gemini 生成标签混合 SFT。
- **自我改进循环**：Gemini 任务生成器 + 奖励模型评分 → 自生成经验库 → 后续迭代训练，无需人类干预。
- **成绩**：训练过环境 65% 成功率（人类 75%）；未见游戏从 SIMA1 的 15-30% 提升到 45-75%。
- **明确短板（官方承认）**：为低延迟砍长期记忆（有限上下文）；键鼠精确控制仍是挑战；长程多步复杂任务仍难。
- **可借鉴**：
  1. **VLM 任务生成器 + 奖励模型的自改进循环** = 我们 CLAUDE.md Tier 2 离线 PPO 的奖励来源可升级为 VLM 评分（避免手写 reward 工程）。
  2. **混合标签训练**（人类演示 + VLM 生成标签）：缓解我们意图弱监督（审查 P5 的 HEAL/RESCUE 零样本）——可用 VLM 辅助标注补视觉依赖类。
  3. **反证**：它砍长期记忆换来低延迟，而第五人格决策依赖对局记忆（监管者位置/修机进度）——**必须保留 MatchMemory（P11 修复是对的）**。
  4. **反证 2**：纯指令跟随在沙盒游戏能到 65%，但第五人格是 1v4 对抗 + 反作弊环境，比 SIMA 场景难得多——更支持「分层 + 规则兜底」而非单一大模型硬怼。

### 2.5 Cradle（字节，ICML 2025）★ 慢层参考

- **GCC 设定**：截图输入 + 键鼠输出，无内置 API；RDR2 完成 40 分钟主线、Cities: Skylines 建千城、Stardew Valley 农场经营。
- **六大模块**：Information Gathering、Self-Reflection、Task Inference、Skill Curation、Action Planning、Memory。
- **可借鉴**：
  1. **Skill Curation（技能库）** = 我们的「固定操作兜底」（QTE 校准/翻窗走规则不进模型）——一致且被验证。
  2. **Self-Reflection**：慢层在事件触发（受击/爆点）时反思重规划，对应我们感知层事件总线 → 慢层重规划的 P8 设计。
  3. **Memory 模块** = MatchMemory（P11）。
  4. **反证**：Cradle 决策是秒级「输出代码执行」，不适用于 8-30Hz 实时对抗——反证我们需要快层。

### 2.6 对抗游戏 RL 前辈（AlphaStar / OpenAI Five）

- 状态特征 + RL + 自对弈；AlphaStar 用 BC 初始化 + league 训练；OpenAI Five 7.5Hz 打赢 Dota2 职业。
- **对本项目**：BC 初始化 + RL 微调路线一致；AET 非对称训练（双 agent 分训）只在 M4 需要——M2/M3 对手是官方 Bot，天然回避（已在 docs/06 记录）。

## 4. 不建议借鉴（已证伪/不适用）

| 做法 | 为什么不借鉴 |
|---|---|
| SIMA 2 砍长期记忆换延迟 | 第五人格决策依赖对局记忆，必须保留 MatchMemory（P11） |
| Cradle 输出代码级秒级动作 | 不适用于 8-30Hz 实时对抗 |
| 单一大模型端到端（monolithic） | 数据量/算力对第五人格不现实，分层 + 规则兜底更稳 |
| 机器人级大 diffusion 动作空间 | 我们只有 4 连续值，M2 回归头 + M3 轻量 flow matching 足够 |
| FAST DCT+BPE 重 tokenizer | 4 维连续动作用不上，chunk 化思想已吸收 |
| 大规模自对弈（AlphaStar 级） | 算力不可及 + 反作弊风险，M4 再评估 |

## 1. 当前结论

项目处于：**VLA v5 数据管线、三阶段训练（WK→VG→ACT）框架和小规模 GPU 训练均已跑通；尚未有可用于实机 dry-run 的合格 checkpoint，尚未进行正式泛化评估**。

当前架构：

```text
任务指令 + mode
        ↓（episode 内缓存一次）
单帧视觉 backbone M0（每个采集帧最多一次，Qwen3-VL-4B + LoRA）
        ↓
8×8 frozen raw cells → deterministic 2×2 pooling → 4096-dim direct raster
        ↓
FrameFeatureCache（最多 8 帧，最少 3 帧）
        ↓ FiLM(condition_{t-1})
   ┌────┴────┐
   ↓         ↓
slow_temporal  fast_temporal     ← 分离 GRU，2026-09-03 起
   ↓         ↓
慢头       快头
intent/    action chunk
subgoal/   (move_dir/camera/buttons/duration)
context    + confidence + stop/replan
```

这是**单模型共享 backbone + 分离时序编码器 + 两个任务头**。分离时序编码器消除了慢头
（离散分类）和快头（连续控制）对同一份循环权重的竞争；FiLM 条件融合仍在分叉之前，是
两者共用且可控的耦合点（`detach_slow_condition` 开关）。详见
[15-快慢VLA接口与时序缓存协议.md](15-快慢VLA接口与时序缓存协议.md) 第 3、6 节和
[18-架构变更历史.md](18-架构变更历史.md)。

捕获频率和快头频率解耦：捕获 30 FPS 写入缓存，快头按固定 deadline 独立运行（目标 15 Hz），
慢头约 1 Hz 或事件触发。

## 3. 当前数据状态

### 3.1 WK

位置：`idv_agent/data/wk/wk_train.jsonl`（70 条，五类 topic 各 14 条，三种模式均覆盖，全部 `verification.status=reviewed`）。WK 不来自 session，不含动作标签。当前协议不保留独立验证集，70 条全部训练；验收从训练集生成确定性语义变体，结果只代表训练内语义一致性，不能据此宣称跨样本泛化。

### 3.2 VG/YOLO

已有一局 session 的完整标注池（129 张图片，94 个框；`frame_states.jsonl`/`vg_annotations.jsonl`/`vg_grounding.jsonl`/`frame_qa.jsonl` 均已生成）。这只能作为标注池和训练管线验证，**不能报告泛化性能**——样本来自单局。

### 3.3 VLA ACT

已有 raw session 保留原始数据；历史批次曾生成 v4 chunks。v5 主线要求从 raw session 重新提取 `per_frame_actions.csv`，并生成独立的 `vla_chunks_v5.jsonl`，不覆盖旧 v4。

历史 `anchor_stride=12` 的 v5 集含有相邻 24 帧 action horizon 重叠，已废弃为训练来源。当前 99 个 raw session 按 canonical `anchor_stride=24`、`history_stride=3`、`history=8`、`horizon=4`、`macro_frames=6` 重建，未来标签窗口连续且互不重叠；原始帧、事件、Raw Input 鼠标位移和 intent 标注未修改。

当前 ACT 实验数据为 `data/mvp_vla_v5_event_centered_decision_label_v2`：train **732 chunks（79 sessions）**，val **182 chunks（20 sessions）**，session 零重叠。100 个 Q 边沿均进入 event-centered 样本（79/20），动作从 Q 帧开始；观测帧仍保留 `q-2` 的真实历史语义，顶层决策标签则按 Q 帧固定为 `decipher/start_decoding`，原始人工段 ID 保留在 `auxiliary.source_segment_id`。训练增强仅作用于训练 forward，采用共享 window 参数的 hue ±0.05、saturation/brightness/contrast 0.8～1.2、平移 ±8 px；验证路径和 raw/v5 文件不增强。

三阶段 checkpoint 均已产出（`checkpoints/M1_WK`、`checkpoints/M2_VG`、`checkpoints/M3_ACT/*`），但**当前没有任何 M3_ACT 候选达到可进入 dry-run 的标准**。最新 m21（base Qwen、M2 不加载、2080 Ti 本机、4 epoch）通过 k=8 深层空间特征门禁和 intent 的画面依赖，但完整 182 条 session-held-out 上 camera 的 image-zero/image-shuffle 差距均小于 0.05，move 的 image-shuffle 也未达门禁。Q 独立事件头的训练集校准 recall=94.94%、逐步 FPR=1.83%，但 held-out 仍有误触发；m18/m19/m20/m21 全部仅作诊断，不得接入 dry-run/部署。camera 需要补“可见密码机相对位置/朝向/交互可达”同源标注；继续加步数没有证据会解决这个缺口。

逐次实验的详细数值不再堆积在本文，见 [17-三阶段训练继承协议.md](17-三阶段训练继承协议.md) §5 的结论摘要和对应 commit。

## 5. 唯一下一步顺序

### 数据侧（用户执行）

1. 新录制 session 先运行 `validate_vla_raw.py`；
2. 用 `init_intent_segments.py` 生成候选片段，人工只确认顶层 intent，再跑 `validate_intent_segments.py`；
3. 构建 v5 chunks（`build_vla_chunks.py --schema-version vla.action_chunk.v5`，输出命名为 `vla_chunks_v5.jsonl`）；
4. VG 数据跑 `infer_frame_states.py`，抽查后生成 annotations/grounding/frame QA。

### 训练侧（代码执行）

1. 先将其余合格 raw session 全部重建为 v5，并运行 v5 audit；
2. 先对 spatial-cell ACT 做分层诊断（cell projector → FiLM → fast GRU → heads），找出跨场景信号从何处再次共线；在画面活性与四组依赖 gate 通过前，不得启动正式规模训练；
3. 以 `detach_slow_condition=True` 做对照，判断 FiLM 残留耦合是否压制空间残差；若仍失败，评估把视觉 residual 直接接入 FastVLAHead；
4. 同时解决移动方向塌缩：基于训练集全局统计的类别权重或九方向分桶采样；
5. 用 `evaluate_vla.py` 扩展到完整留出 session，按意图/状态分桶报告指标；
6. 对每个候选 checkpoint 运行 `evaluate_visual_dependency.py` 四组画面依赖验收；未通过不得进入 dry-run；
7. 仅对通过画面依赖 gate 的 checkpoint 接入 VLA dry-run 与滚动 action chunk 调度（`run_agent --mode act`），确认安全门和延迟预算；
8. 仅在官方自定义剧本/训练营进行极短真发送测试。

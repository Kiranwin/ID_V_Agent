# 05 · 操作手册

端到端实操：录制 → 构建 → 统计 → 训练 → 部署。所有命令以项目根目录为当前目录。

## 0. 前提

- 管理员权限（NeAC 阻断非管理员 hook）。
- 依赖已装（见 docs/04）。
- 游戏窗口已开，自定义剧本已配置。

## 1. 录制

```bash
# 列出游戏窗口标题（确认窗口名）
python -m idv_agent.scripts.record --list-windows

# 开始录制（Ctrl+C 停止；或用 --max-seconds 自动停止）
python -m idv_agent.scripts.record --window-title "Identity V"
```

- 录制启动后立即采集；按 Ctrl+C 安全停止。别 Alt+Tab（窗口必须前台），关 OBS/浏览器视频保持稳定 fps。
- 自然打出好操作，尽量覆盖 20 类动作（破译时长按、校准 Space、翻窗、救人是重点）。
- 打出的会话在 `data/sessions/<session_id>/`。

## 2. 提取动作 + 构建 JSONL

建议先做会话完整性检查：

```bash
python -m idv_agent.scripts.validate_session --session-dir data/sessions/<session_id>
```

检查通过（`PASS`）后再执行提取和构建。

```bash
# 从 events.csv + mouse_positions.csv + frames 提取 per_frame_actions
python -m idv_agent.scripts.extract --session-dir data/sessions/<session_id>

# 构建训练用 samples.jsonl
python -m idv_agent.scripts.build_jsonl --session-dir data/sessions/<session_id>
```

产物：《docs/03-数据格式》的 `samples.jsonl` + `intents.csv`。

## 3. 数据统计（P4 验证）

```bash
python -m idv_agent.scripts.stats --session-dir data/sessions/<session_id>
```

输出 category_id / intent 分布，确认 RESCUE/VAULT/SKILL 等长尾是否缺样本。

## 4. 无 GPU / 无游戏冒烟测试

```bash
python -m idv_agent.scripts.smoke_test
```

验证：模型 forward（dummy 主干）、Dataset/Collator、提取管线（合成事件），全部 CPU 可跑。

## 5. 训练

```bash
# 快层 BC（小策略网络）
python -m idv_agent.scripts.train_fast \
    --session-dir data/sessions/<s1>,data/sessions/<s2> \
    --output-dir checkpoints/fast_run1 \
    --batch-size 8 --fp16

# 慢层 BC（VLM 三头）
python -m idv_agent.scripts.train_slow \
    --session-dir data/sessions/<s1> \
    --output-dir checkpoints/slow_run1 \
    --fp16
```

- 输出目录自动加时间戳，旧 ckpt 自动备份（`backup_<ts>/`）。
- 2080 Ti 用 `--fp16` + GradScaler；先跑 1 epoch 验证链路再调大。
- 需要 `--model-ckpt` 时传入 Qwen 路径 / SigLIP 路径。

## 6. 部署（Agent）

### M1 找机闭环（模板模式）

先在游戏中让密码机出现在画面，保存一张只读模板候选帧：

```bash
python -m idv_agent.scripts.benchmark_capture --title "第五人格" --seconds 5 --save-frame outputs/cipher_candidate.jpg
```

从候选帧裁剪出密码机本体（保持与部署相同分辨率），例如保存为 `outputs/cipher_template.jpg`，再运行。遮挡场景的黄色高亮信标无需单独模板，检测器会自动识别；模板用于无遮挡的 3D 机器本体：

```bash
python -m idv_agent.scripts.run_agent --mode rule --title "第五人格" \
  --cipher-template outputs/cipher_template.jpg --duration 10 --dry-run
```

确认离线/dry-run 日志中的 `visible/position/distance` 后，才允许在官方自定义剧本做极短真发送。

```bash
# 规则 agent（律师版「找→走→破译」闭环，dry-run）
python -m idv_agent.scripts.run_agent --mode rule --dry-run

# 学习型快层
python -m idv_agent.scripts.run_agent --mode fast --fast-ckpt checkpoints/fast_run1/best.pt --dry-run

# 真实注入（仅自定义剧本/训练模式！）
python -m idv_agent.scripts.run_agent --mode rule --send-input
```

F12 随时紧急退出（会释放所有按住的键）。

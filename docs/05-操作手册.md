# 05 · 操作手册

端到端实操：录制 → 构建 → 统计 → 训练 → 部署。所有命令以项目根目录为当前目录。

## 0. 前提

- 管理员权限（NeAC 阻断非管理员 hook）。
- 依赖已装（见 docs/04）。
- 游戏窗口已开，自定义剧本已配置。

## 1. 录制

```bash
# 列出游戏窗口标题（确认窗口名）
python -m idv_agent.scripts.record --list-windows

# 开始录制（Ctrl+C 停止；或用 --max-seconds 自动停止）
python -m idv_agent.scripts.record --window-title "Identity V"
```

- 录制启动后立即采集；按 Ctrl+C 安全停止。别 Alt+Tab（窗口必须前台），关 OBS/浏览器视频保持稳定 fps。
- 自然打出好操作，尽量覆盖 20 类动作（破译时长按、校准 Space、翻窗、救人是重点）。
- 打出的会话在 `data/sessions/<session_id>/`。

## 2. 提取动作 + 构建 JSONL

建议先做会话完整性检查：

```bash
python -m idv_agent.scripts.validate_session --session-dir data/sessions/<session_id>
```

检查通过（`PASS`）后再执行提取和构建。

```bash
# 从 events.csv + mouse_positions.csv + frames 提取 per_frame_actions
python -m idv_agent.scripts.extract --session-dir data/sessions/<session_id>

# 构建训练用 samples.jsonl
python -m idv_agent.scripts.build_jsonl --session-dir data/sessions/<session_id>
```

产物：《docs/03-数据格式》的 `samples.jsonl` + `intents.csv`。

## 3. 数据统计（P4 验证）

```bash
python -m idv_agent.scripts.stats --session-dir data/sessions/<session_id>
```

输出 category_id / intent 分布，确认 RESCUE/VAULT/SKILL 等长尾是否缺样本。

## 3.1 密码机 YOLO 标注数据准备

按局划分 train/val，抽取帧并创建 YOLO 目录（不会自动伪造框）：

```bash
python -m idv_agent.scripts.prepare_yolo_dataset \
  --sessions 20260831_113220,20260831_131040,20260831_131904,20260831_132206 \
  --output data/yolo_cipher --stride 5
```

类别固定为：`0=cipher_visible`（可见 3D 密码机）、`1=cipher_highlight`（墙后黄色高亮）、`2=interact_prompt`（扳手/Q 交互提示）、`3=decoding_state`（“破译密码”文字与进度条区域）。

标注细则：

- `cipher_visible` 只框画面中实际可见的机器几何部分；被角色/墙体遮住的部分不要脑补补框。
- `cipher_highlight` 只框黄色高亮本体/天线，不框墙体和 HUD。
- `interact_prompt` 紧框扳手图标及其 `[Q]` 提示（如两者分离，合并成一个能覆盖二者的最小矩形）；这是允许发送 Q 的证据。
- `decoding_state` 紧框“破译密码”文字和黑色进度条；进入该类后视为已按 Q，规则层锁存 `interacting=yes`，禁止重复按 Q。
- HUD 被遮挡时只框实际可见区域；不确定是否为目标时留空，作为困难负样本。

使用 CVAT、LabelImg 或 Roboflow 打开 `data/yolo_cipher/images/*`，将框写入对应的 `labels/*/*.txt`；每行格式为 `class_id x_center y_center width height`，坐标归一化到 0～1。没有目标的帧保留空 txt。标注完成后先检查 `manifest.csv` 中 train/val 未混入同一局，再进入 YOLO 训练。

## 4. 无 GPU / 无游戏冒烟测试

```bash
python -m idv_agent.scripts.smoke_test
```

验证：模型 forward（dummy 主干）、Dataset/Collator、提取管线（合成事件），全部 CPU 可跑。

## 5. 训练

```bash
# 快层 BC（小策略网络）
python -m idv_agent.scripts.train_fast \
    --session-dir data/sessions/<s1>,data/sessions/<s2> \
    --output-dir checkpoints/fast_run1 \
    --batch-size 8 --fp16

# 慢层 BC（VLM 三头）
python -m idv_agent.scripts.train_slow \
    --session-dir data/sessions/<s1> \
    --output-dir checkpoints/slow_run1 \
    --fp16
```

- 输出目录自动加时间戳，旧 ckpt 自动备份（`backup_<ts>/`）。
- 2080 Ti 用 `--fp16` + GradScaler；先跑 1 epoch 验证链路再调大。
- 需要 `--model-ckpt` 时传入 Qwen 路径 / SigLIP 路径。

## 6. 部署（Agent）

### 5.1 局部预测导航数据准备

在固定 YOLO 检测器后，采集包含“朝密码机移动、遇障碍绕行、重新对齐、进入交互”的完整片段。每局录制完成并提取动作后，生成 3 帧历史 → 未来 4 个宏动作（每个约 0.2 秒、总预测约 0.8 秒）清单：

```bash
python -m idv_agent.scripts.build_nav_sequences \
  data/sessions/<session_id> --history 3 --stride 3 --horizon 4 --macro-frames 6
```

宏动作固定为 `forward`、`left`、`right`、`stop_observe`。视角 `cam_dx/cam_dy` 作为连续辅助标签保留，不与宏动作类别混合；产物为 `nav_sequences.jsonl`，只含帧路径和动作元数据，不修改原始 session。后续用它训练 SigLIP2/时序控制头；Qwen 仍只做低频高层规划。

### M1 找机闭环（模板模式）

先在游戏中让密码机出现在画面，保存一张只读模板候选帧：

```bash
python -m idv_agent.scripts.benchmark_capture --title "第五人格" --seconds 5 --save-frame outputs/cipher_candidate.jpg
```

从候选帧裁剪出密码机本体（保持与部署相同分辨率），例如保存为 `outputs/cipher_template.jpg`，再运行。遮挡场景的黄色高亮信标无需单独模板，检测器会自动识别；模板用于无遮挡的 3D 机器本体：

```bash
python -m idv_agent.scripts.run_agent --mode rule --title "第五人格" \
  --cipher-template outputs/cipher_template.jpg --duration 10 --dry-run
```

密码机检测在慢层执行，默认间隔 4 秒；可用 `--cipher-detect-interval 3`～`5` 调整。每次检测会输出一行 `[cipher] detect ...`，并在结束时汇总次数和最后结果，便于后续回放标注。

确认离线/dry-run 日志中的 `visible/position/distance` 后，才允许在官方自定义剧本做极短真发送。

### 5.2 视觉伺服基线与示范轨迹采集

> VLA 训练数据请使用独立的 `record_vla`，不要继续使用旧 `record` 录制后直接
> 混入训练。旧 session 仅作调试，不进入 VLA 数据集。

```powershell
python -m idv_agent.scripts.record_vla `
  --window-title "第五人格" `
  --fps 30 `
  --max-seconds 60 `
  --output data/vla_raw_sessions
```

录制结束后先校验：

```powershell
python -m idv_agent.scripts.validate_vla_raw data/vla_raw_sessions/<session_id>
```

确认通过后再做意图、质量和成功阶段标注，最后构建 `vla_chunks.jsonl`。

M1 规则模式默认使用视觉伺服：以屏幕中心为角色前向轴，先用密码机 bbox
水平误差调整视角，进入中心走廊后前进；面积只记录为诊断量，不单独判断距离。
出现 `interact_prompt` 连续确认后只按一次 Q，检测到 `decoding_state` 后保持破译。
目标已出现时检测间隔会自动缩短到约 0.25 秒，便于连续闭环。

在官方自定义剧本/训练营中先用 dry-run 检查动作，再进行短时真发送并保存示范轨迹：

```bash
# 安全演练：只打印动作，同时保存状态/动作 JSONL 和对应画面
python -m idv_agent.scripts.run_agent --mode rule --title "第五人格" \
  --yolo-model runs/detect/checkpoints/yolo/cipher_v1-2/weights/best.pt \
  --trajectory-log outputs/trajectory_demo.jsonl \
  --trajectory-frames outputs/trajectory_frames \
  --duration 30 --dry-run

# 确认无误后，仅在自定义剧本/训练模式、管理员终端执行真发送
python -m idv_agent.scripts.run_agent --mode rule --title "第五人格" \
  --yolo-model runs/detect/checkpoints/yolo/cipher_v1-2/weights/best.pt \
  --trajectory-log outputs/trajectory_demo.jsonl \
  --trajectory-frames outputs/trajectory_frames \
  --duration 30 --send-input
```

每行 JSONL 包含 `spatial`（bbox 中心/底部/提示状态）、离散动作、连续视角量和
执行命令；`trajectory_frames/` 保存同帧图像。完成“找到→靠近→出现扳手→Q→破译”
的片段标记为成功，卡墙、目标丢失或误交互片段保留为失败样本，供后续局部预测模型
学习安全边界。

```bash
# 规则 agent（律师版「找→走→破译」闭环，dry-run）
python -m idv_agent.scripts.run_agent --mode rule --dry-run

# 学习型快层
python -m idv_agent.scripts.run_agent --mode fast --fast-ckpt checkpoints/fast_run1/best.pt --dry-run

# 真实注入（仅自定义剧本/训练模式！）
python -m idv_agent.scripts.run_agent --mode rule --send-input
```

F12 随时紧急退出（会释放所有按住的键）。

# 08 · 当前执行计划

> 这是面向当前分支的任务清单，不再使用旧的“BC M2 → VLA M3”强制顺序。
> 每完成一项就更新 [docs/00-当前状态.md](00-当前状态.md)。

## P0 · 现在执行：数据闭环

| 顺序 | 任务 | 产物/验收 |
|---|---|---|
| 1 | 校验 raw session | `validate_vla_raw` 通过 |
| 2 | 生成并确认 intent segments | 全帧覆盖、无重叠 |
| 3 | 自动生成 VG frame states | `frame_states.jsonl`，抽查状态 |
| 4 | YOLO → VG → frame QA | 三类文件可重复生成 |
| 5 | 构建 v4 chunks | `vla_chunks_v4.jsonl` 通过校验 |

## P1 · 最小 VLA 训练闭环

1. 接入 Qwen 单帧视觉 backbone；每个 episode 只缓存一次 instruction/mode embedding。
2. 接入真实图片 collator 和 8 帧窗口读取。
3. 用 dummy/小数据完成 forward、联合 loss、backward、checkpoint。
4. 在 RTX 2080 Ti 用 FP16 + GradScaler 跑通一个小 epoch，记录显存/延迟。

## P2 · 辅助数据与部署验证

1. 仅使用 verified WK；VG 用于 grounding/空间辅助训练，不直接替代 ACT 标签。
2. 离线回放检查动作块的时间对齐、连续性和停止/重规划信号。
3. VLA dry-run：捕获频率与快头频率解耦，缓存取最新窗口。
4. 仅在官方自定义剧本进行极短真发送；任何异常立即回退规则安全门。

## P3 · 远期扩展

- 模式 token + LoRA（联合狩猎、黑杰克）。
- 更多角色、地图、救援/治疗/道具动作。
- 评估集、失败回放和世界知识后训练（ActVLP 启发）。

## 当前不做

- 不恢复旧 BC 管线。
- 不为每个动作建立独立旧式分类器。
- 不在没有数据和离线回放证据时直接做长时间真发送。

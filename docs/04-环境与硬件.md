# 04 · 环境与硬件

## 硬件基线

- GPU：**RTX 2080 Ti 22GB**（Turing，CC 7.5）。
  - **无原生 BF16** → 训练必须 FP16 + GradScaler。无 FlashAttention 3。
  - Qwen3-VL-4B FP16 + LoRA + heads，batch=1 forward+backward ≈ 8.5 GB / 22GB，余量充足。
- 可租云 GPU（VLA 微调用）：租 4090/A100 按需；具体模型规模以本地显存和延迟实测为准。
- VLA 推理在本地 2080 Ti 的延迟尚未验收；优先采用特征缓存 + action chunk，再根据实测决定量化、云推理或降低频率。

## 反作弊操作知识（NeAC）

《第五人格》使用网易 NeAC 内核级反作弊。两个关键后果：

1. **录制必须管理员权限**。非管理员时 pynput 用户态键鼠 hook 被系统隔离（UIPI integrity）——游戏内 W/A/S/D/Q/Space 全部吞掉，只收到系统事件。提升管理员后放行。
2. **真机注入有风险**。`pydirectinput`（SendInput）带 `LLMHF_INJECTED` 标志，排位/匹配会被检测。**默认 `RealtimeAgent` 跑 dry-run**（只打印命令不发键）；仅 `--send-input` 且在自定义剧本/训练模式启用，**绝不**用排位。

## 游戏 / 沙盒配置

- 官方 PC 互通版，自定义剧本：3 Bot 队友 + 1 Bot 监管者（难度可调）。
- 确认键位与 `idv_agent/configs/keymap.py` 一致（改键请编辑该文件）。
- **合规红线**：不碰真人排位自动化、不用内存读取 / DLL 注入 / 截帧 hook（野战行动规则点名 RenderDoc/WinPix/Nsight，DLL 注入是内核反作弊最高危行为）。

## M0 验收记录

- 管理员终端下真发送测试通过；300 帧、约 30 FPS。
- 抓帧 p95 4.97ms，总链路 p95 5.96ms，满足当前延迟门槛。
- 合规边界固定为官方自定义剧本/训练营，默认 dry-run。

## M1 出口条件

1. 至少一份 raw session 通过完整性校验。
2. intent segments 覆盖全部帧且无重叠；subgoal 由规则派生。
3. VG 的 YOLO、frame state、grounding、frame QA 产物可重复生成。
4. 能从同一 session 构建并校验 `vla.action_chunk.v4`。

## M2 出口条件

1. dummy backbone → 时序编码器 → 快慢头的 forward/loss/backward 全部通过。
2. 真实图片 collator、FP16 + GradScaler 单 epoch 在 2080 Ti 跑通。
3. checkpoint 保存/恢复和 episode 级文本条件缓存可用。

## 不纳入当前主线

- 旧 `bc_fast`/`bc_slow`、旧 `samples.jsonl`、旧逐帧 Actor-Critic。
- 以 YOLO 检测结果直接替代 VLA 输入的训练路径。
- 真人排位/匹配中的任何自动注入。

# 17 · WK → VG → ACT 三阶段训练继承协议

本文冻结三阶段 checkpoint 的继承关系，避免 WK、VG、ACT 各自从原始 Qwen 权重开始训练，导致知识能力无法进入最终 VLA。

## 1. 唯一继承链

```text
Qwen3-VL base B0
  └─ WK LoRA → M1_WK = B0 + lora_wk
       └─ VG（冻结 lora_wk，训练 lora_vg/grounding）→ M2_VG
            └─ ACT（加载 M2_VG，训练时序/快慢头）→ M3_ACT
```

标准模式 M3_ACT 是共享底座；联合狩猎和黑杰克从 M3_ACT 继续，只添加各自 mode LoRA。

## 2. 阶段规则

- WK：从 B0 开始，只训练语言层 `lora_wk`，视觉塔冻结，输出 `M1_WK`。
- VG：必须从 M1_WK 加载，保留并冻结 `lora_wk`，训练视觉 grounding 投影/头，输出 `M2_VG`。`lora_vg` 作为后续容量扩展保留在协议中；当前实现和 manifest 不虚构该适配器。
- ACT：必须从 M2_VG 加载；第一轮冻结 Qwen、`lora_wk`、`lora_vg`，只训练单帧投影、共享 GRU、FiLM、Slow Head、Fast Head；稳定后才允许小学习率解冻顶部 LoRA，输出 `M3_ACT`。

每个阶段都必须保存 `manifest.json`，记录 `stage`、`parent`、base model、adapters、冻结/可训练参数、数据版本和 schema 版本。统一协议实现于 `idv_agent/training/checkpoint_manifest.py`，可用 `python -m idv_agent.scripts.validate_checkpoint_manifest <checkpoint_dir>` 校验。

## 3. 合并与部署

实验阶段保留独立 adapter：`B0 + lora_wk + lora_vg + heads`。发布时可按顺序合并，但必须保留未合并备份。模式适配器为 `M3_ACT + lora_joint_hunt` 或 `M3_ACT + lora_blackjack`，卸载即回到标准 M3_ACT。

仅把 `lora_wk` 文件放在目录中不算继承。ACT 的任务/指令 embedding 或多模态条件路径必须实际来自 M1_WK/M2_VG，并在 smoke test 中验证加载前后语义输出变化。

## 4. WK 入口已实现

`idv_agent/scripts/train_wk_lora.py` 提供 M1_WK 的文本 SFT/LoRA 入口：

```powershell
python -m idv_agent.scripts.train_wk_lora `
  --data data/wk_vg/wk/wk_train.jsonl `
  --model-path C:/path/to/Qwen3-VL-4B-Instruct `
  --val-fraction 0.1 `
  --output-dir checkpoints/M1_WK `
  --steps 100
```

它只接受 `reviewed/verified` 样本，使用 `<mode:...>` 条件 token，2080 Ti 上启用 FP16 +
GradScaler，并输出 `adapter/`、`processor/`、`manifest.json` 和 `metrics.json`。manifest
包含 `checkpoint.manifest.v1`、WK 文件 SHA-256、训练参数、统计信息和 artifact 路径。先用
`--dry-run` 检查数据格式；`--val-data` 与训练文件存在重复 ID 时会主动报错。

## 5. 当前实现与验证状态

三阶段入口和 manifest 校验已经落地：

- `train_wk_lora.py` 生成 `checkpoints/M1_WK`；
- `train_vg_grounding.py` 从 M1_WK 继承并生成 `checkpoints/M2_VG`；
- `train_vla.py --init-checkpoint checkpoints/M2_VG` 加载 M1_WK 的 `lora_wk` 与 M2_VG 的视觉投影，冻结 Qwen 视觉塔和 WK LoRA，训练 ACT 投影、时序编码器、FiLM 及快慢头，生成 `checkpoints/M3_ACT`；
- `validate_checkpoint_manifest --require-artifacts` 已通过，当前 M3_ACT manifest 的 `counts.val=0` 明确表示这是训练子集闭环，不是泛化验证。

当前 M3_ACT 运行记录均用于管线验收，不作为模型效果结论：最小闭环为 32 条样本、20 steps（baseline loss 8.2816 → final 4.7003，slow accuracy 0.6563）；随后完成 7 局训练 session（均匀取 128 条）+ 第 8 局独立验证（跨整局均匀取 16 条）的 100-step 小规模实验（train loss 8.4118 → 0.2801，train slow accuracy 0.3672，val loss 2.2433，val slow accuracy 0.25）。两次实验均为 FP16+GradScaler，峰值显存约 9076 MiB，保存后恢复 loss delta=0。验证集和训练步数仍很小，下一步需扩充留出集、增加训练量，再做离线回放和 dry-run。

离线评估入口 `idv_agent/scripts/evaluate_vla.py` 已加入，强制校验 M3_ACT manifest 后只读取图片和 v4 标签，不发送任何输入。第 8 局 16 条均匀样本的 sanity check 结果保存在 `reports/vla_eval_20260901.json`；正式结论需在完整留出 session 和按意图分桶后再报告。

完整第 8 局留出评估（2214 条样本、2221 张唯一帧）已生成 `reports/vla_eval_20260901_full.json`：move=0.5845、camera dx/dy=0.9982/1.0、button element/exact=0.9192/0.5254、duration MAE=0.0918 帧、intent=0.2480、loss=2.2211。该模型仅训练 100 steps，指标用于离线基线和回归检查，不作为泛化或实机效果承诺。

正式扩步训练已完成：6 局训练 session 均匀取 1024 条，2 局独立 session 均匀取 128 条验证，500 steps、学习率 1e-4，产物为 `checkpoints/M3_ACT/act_formal_500.pt`。训练 loss 8.3557→1.1925、train slow accuracy 0.4951；val loss 1.5913、val slow accuracy 0.1641。该 checkpoint 已通过 manifest 校验，可作为下一轮离线回放的候选；验证意图准确率仍偏低，不能直接进入实机控制。

为处理动作分布不平衡，另完成 stop 类权重 0.25、按键正例权重 4.0 的 `act_balanced_500.pt`。两局完整留出评估显示非停止移动准确率 61.89%（未加权版本为 0），但按键正例召回仍为 0、意图准确率 15.53%；因此该版本仅用于诊断，不进入 dry-run，下一步应对移动/按键进行重采样并补充交互片段。

重采样实现于 `train_vla.py --sampling stratified --seed 7`：以完整 action chunk 为单位分为 `interact/move/other_key/stop` 四层，默认配额 35%/35%/15%/15%，层内按 episode 轮转，验证集保持原始分布。例如：

```powershell
python -m idv_agent.scripts.train_vla `
  --data <train-session-1.jsonl,...> --val-data <holdout-session.jsonl> `
  --sampling stratified --seed 7 --max-samples 1024
```

该策略只改变训练索引，不修改帧、事件或标签；如果某层样本不足，缺口自动从剩余样本补齐。

分层采样训练产物 `checkpoints/M3_ACT/act_stratified_500.pt` 已完成完整留出评估：按键正例 precision/recall=60.72%/96.42%，但 move 非停止准确率仍为 0（总体 move=71.19% 由 stop 多数类贡献），意图准确率 22.89%。因此下一轮应将移动分类单独做 class-balanced loss 或提高 `move_stop_weight` 的下调幅度，不能仅继续提高采样比例。

九方向平衡实验 `checkpoints/M3_ACT/act_direction_balanced_500.pt` 使用 batch 内 inverse-sqrt 方向权重，val loss=1.4075；完整留出集的 move 预测仍全部集中在 north（非停止方向准确率 0）。结论是方向权重必须基于训练集全局统计或配合九方向分桶采样，不能使用每个 batch 的局部频率。
